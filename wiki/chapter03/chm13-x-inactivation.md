## Question (원문 / Original)

X chromosome inactivation에 관련하여 질문드립니다. 교재에서 CHM13의 한계 중 X inactivation pattern이 나와있습니다. 일반적인 여성의 경우 X염색체가 하나 불활성화되는데, 교재의 표현에서 "CHM13's pattern may differ"라는 표현에 의구심이 들어 질문드립니다. CHM13의 경우 maternal DNA없이 정자의 DNA를 두배시켜 만든 cell line인데, 어떻게 (여성의 유전정보가 있을수가없는) CHM13에서 X inactivation의 pattern이 존재 할 수 있는것인가요?

## Question (Translation)

I have a question regarding X chromosome inactivation. The textbook lists X inactivation pattern as one of the limitations of CHM13. In typical females, one X chromosome is inactivated, and the textbook's phrasing "CHM13's pattern may differ" prompted my question. Given that CHM13 is a cell line created by doubling sperm DNA without any maternal DNA, how can an X inactivation pattern exist in CHM13, which cannot contain female genetic information?

## Answer (원문 / Original)

1번에 대해.

CHM13은 단순히 "duplication된 cell line"이라기보다, 정자 유래 haploid genome이 duplication되어 형성된 complete hydatidiform mole 유래 세포주입니다. 이 경우 maternal X chromosome이 존재하지 않고, 하나의 X chromosome이 복제된 형태이므로 두 X가 서로 구별되지 않습니다. 따라서 일반 여성에서처럼 서로 다른 두 X 중 하나를 무작위로 비활성화하는 X inactivation 과정이 필요하지 않으며, 정상적인 의미의 X inactivation pattern도 형성되지 않습니다. 교재의 "CHM13's pattern may differ"라는 표현은 CHM13이 이러한 epigenetic 상태를 대표하지 못하므로 일반적인 여성의 X inactivation과 직접 비교하기 어렵다는 한계를 의미합니다. 또 한가지의 한계는 개인마다 X inactivation 패턴도 다르기 때문에, 이것에 대한 일반화 하는 정보를 제공하긴 어렵지요.

## Answer (Translation)

Regarding this question:

CHM13 is not simply a "duplicated cell line" but rather a cell line derived from a complete hydatidiform mole, formed by the duplication of a haploid genome originating from sperm. In this case, no maternal X chromosome is present; instead, a single X chromosome has been duplicated, so the two X chromosomes are identical and indistinguishable from each other. As a result, there is no need for the process of randomly inactivating one of two distinct X chromosomes as occurs in typical females, and a normal X inactivation pattern does not form. The textbook's phrasing "CHM13's pattern may differ" refers to the limitation that CHM13 does not represent this epigenetic state, making it difficult to directly compare with typical female X inactivation. An additional limitation is that X inactivation patterns vary among individuals, making it difficult for CHM13 to provide generalizable information on this topic.
